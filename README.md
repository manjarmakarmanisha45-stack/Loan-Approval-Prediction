# 🏦 Loan Approval Prediction

## 📌 About the Project
Loan Approval Prediction is a Machine Learning project that predicts whether a loan application is likely to be approved or rejected based on applicant details.

## 🎯 Objectives
- Predict loan approval using Machine Learning.
- Compare different classification algorithms.
- Provide a simple web interface for users.

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Scikit-learn
- Gradio
- Joblib

## 🤖 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## 📊 Model Performance
The selected Logistic Regression model achieved approximately **86.18% test accuracy** during evaluation.

## 💻 Features
- User-friendly web interface
- Applicant information input form
- Loan approval prediction
- Approval and rejection results

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/manjarmakarmanisha45-stack/Loan-Approval-Prediction.git
   ```

2. Open the project folder:
   ```bash
   cd Loan-Approval-Prediction
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal.
